There is a shared storage within the processing area where you can place items into, however every interaction with the storage is logged.

<Warning>
  The shared storage should only contain confiscated items from inmates and visitors. You should NOT place fingerprints or notepads into them. Furthermore every access to the storage is monitored and if you are caught taking items that are not meant to be returned out of there, you will face consequences up to termination from the department.
</Warning>
